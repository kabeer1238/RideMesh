# Privacy note — vc26

RideMesh shares live location only while a rider participates in an active RideMesh ride. The optional phone number, when supplied, is shared only inside that active ride so permitted rider actions such as Call, WhatsApp and Message can be offered.

Location and optional phone data are separate from voice audio. Ending/leaving the ride stops live location publishing. Public App Store / privacy-policy disclosures should describe both active-ride location sharing and optional phone-number sharing before public release.
