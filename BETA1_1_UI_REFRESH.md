# RideMesh Beta 1.1 — UI refresh

Build identity: `0.4.2-beta1.1` (`versionCode 12`).

## Presentation
- Proper adaptive Android launcher icon using the chosen RideMesh icon artwork.
- App label standardized to `RideMesh`.
- Existing splash retained but made slightly smaller/faster for a more subtle opening.
- New landing/home screen with a premium dark RideMesh hero, clear Create/Join actions, readiness status and capability summary.
- Existing view IDs and ride/session behavior are preserved.

## Safety / usability
- Landing page states that setup should be done while stopped.
- The hands-free nature of normal active ride mode remains explicit.
